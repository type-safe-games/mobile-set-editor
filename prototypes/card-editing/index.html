How should a phone-portrait user edit a card?

Three ways to edit a magic card on a phone held upright. All three share the same field editors, art crop and card render; only where the editing happens changes. Flip with the bar at the bottom or the ← → keys.

Core render latency

The C++ core renders the card off-screen and hands the UI a finished bitmap. Raise this to feel how each variant copes when the card lags behind your typing.
